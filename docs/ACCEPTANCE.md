# MVP 验收清单

## 快速试用

1. 从官网会员入口 `http://127.0.0.1:3001/account` 进入工具
2. 工具页展示手机端“AI招商卡生成工作台”
3. 粘贴一段项目说明文本
4. 可选填写联系人、联系电话
5. 可选上传 0 到 1 张展示图片；单张原图不超过 8MB
6. 在“生成风格”中选择 12 套配色之一
7. 点击“整理资料”
8. 点击“开始生成”
9. 在“生成结果”中确认图片可预览，推荐卡图片内不显示生成码
10. 在“我的生成”中能看到当前员工自己的历史记录；推荐卡图片内不显示生成码

## 功能验收

- 未通过官网会员授权时，生产环境不能生成推荐卡
- 工具站不再展示独立员工登录和员工注册两套入口
- 本地开发环境可开启 demo session；生产环境必须关闭 demo session
- 用户权益归属通过官网 SSO ticket 进入工具，不在工具内填写公司码
- 第一版公开试用不开放工具内管理台
- 公司权益和会员入口合并到官网会员系统
- 每次提交形成独立记录
- 客户前端不提供原始 Excel 下载
- 手机端主入口为文本资料；Excel / CSV 入口仅保留为兼容能力
- 每条项目资料生成一张推荐卡
- 未上传项目图片时仍可生成推荐卡
- 前端和服务端都限制项目图片最多 1 张、原图 8MB 以内
- 服务端拒绝超长项目文案，避免异常请求拖垮生成链路
- 招商卡实时预览默认显示空画布，不默认展示案例图
- 3 张案例图仅作为示例/历史案例展示，不混入用户生成结果预览
- 前端提供 12 套配色按钮，默认白金
- 同一批次内推荐卡保持同一套配色
- 推荐卡默认采用单一主卖点、大留白、克制高级风格
- 生图等待时展示阶段提示，失败时保留资料并提示可重试
- 真实生图版本必须通过本地 Node 服务调用局域网 Image 2 API，不在前端暴露 API Key
- 生成图片必须保存到 `storage/generated`，并返回页面可预览路径
- 每张生成图旁路保存不含 API Key 的 `.json` 元数据，包含生成码、项目名、模型、prompt 快照和原始字段快照
- 每次生成记录包含唯一生成码，推荐卡图片内不显示生成码
- 生成码追溯只进入系统记录和后续服务端管理端，不作为公开查询能力裸露给客户
- 员工生成记录需保留在数据中，客户前端展示“我的生成”
- 轻量版每批最多 30 张

## 上线门禁

- `PROJECT_CARD_ENV=production` 或 `NODE_ENV=production` 时，缺少 `PROJECT_CARD_SSO_SECRET`、`IMAGE_API_BASE_URL`、`IMAGE_API_KEY` 任一项都必须拒绝启动
- `/api/ready` 返回 `ok: true` 后才允许切流
- `/api/config` 不返回任何密钥、供应商地址或供应商品牌
- 生产环境默认关闭 demo session
- 生产环境默认关闭工具内管理端
- 生产环境默认要求生成码查询携带当前账号会话，避免裸查其他公司或员工记录
- 生产环境应设置 `PROJECT_CARD_DATA_DIR`，让生成图片、追溯索引和 SSO 防重放记录保存在 release 目录之外
- 生产环境应设置 `PROJECT_CARD_LOG_DIR=/var/log/project-card-tool` 和 `PROJECT_CARD_TMP_DIR=/var/lib/project-card-tool/tmp`，避免日志和临时请求写入只读 release
- 生产服务应设置 `HOST=127.0.0.1`、`PORT=8773`，只允许 Nginx 从本机反代，不直接暴露 Node 端口
- `storage/generated/**/*.json` 和 `trace-index.json` 静态访问必须返回 403
- `app.js` 不允许出现客户端固定管理口令

## 当前限制

- 当前是浏览器端 + 本地 Node 轻量版，部分历史记录仍会保存在本机浏览器；公开试用可用，长期运营建议迁移数据库
- 工具内管理台已默认关闭；正式管理端需要服务端管理员鉴权和审计
- Excel 解析依赖 SheetJS CDN；手机端主链路不依赖 Excel
- 官网 SSO 已有最小链路；服务端数据库、OSS、线上 worker 尚未接入

## 下一步服务端化

上线版本建议迁移为独立服务：

- 服务端账号和管理员鉴权
- SQLite/PostgreSQL 保存公司、用户、批次、生成记录
- 对象存储保存原始 Excel、上传图片、生成 PNG
- 官网通过一次性 SSO ticket 跳转
- 生成记录和用量记录落库
- 管理后台加操作审计
