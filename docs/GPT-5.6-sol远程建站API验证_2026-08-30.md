# GPT-5.6-sol 远程建站 API 验证（2026-08-30）

## 验证目标

- 确认第三方 OpenAI-compatible 网关是否提供 `gpt-5.6-sol`。
- 验证其能否生成一个完整、自包含、可作为 `index.html` 使用的中文官网页面。
- 验证流式输出能否绕开非流式请求约 45 秒的网关等待超时。
- 本轮不接入客户流程，不修改 Public，不调用生图接口。

## 结果

### 模型发现

- `/v1/models` 鉴权成功。
- 可用相关模型包括：`gpt-5.6-sol`、`gpt-5.6-terra`、`gpt-5.6-luna`。

### 第一轮：非流式 HTML 生成

- 模型：`gpt-5.6-sol`
- 请求方式：`stream=false`
- 客户端等待上限：180 秒
- 结果：约 45 秒后网关返回 HTTP `504`，未交付 HTML。
- 判断：504 来自网关服务端等待上限，不是客户端 180 秒超时。

### 第二轮：流式、精简 HTML 生成

- 模型：`gpt-5.6-sol`
- 请求方式：`stream=true`
- 客户端等待上限：900 秒（`900000ms`）
- HTTP 状态：`200`
- 总耗时：46.6 秒
- 流式事件数：1,843
- HTML 字符数：5,408
- 结构检查：包含 doctype、html、body、内联 style 和闭合 html；不含 Markdown 代码围栏。
- 验证结论：通过。

## 技术结论

- 该网关具备使用 `gpt-5.6-sol` 生成完整 HTML 官网的基础能力。
- 当前必须优先采用流式调用；非流式调用存在约 45 秒网关超时风险。
- `900 秒`是客户端允许持续接收流式数据的最大等待时间，并不能单方面修改第三方网关自身的服务端超时。
- 本次只完成结构兼容性验证，尚未验证复杂客户资料、图片理解、素材本地化、视觉质量、修改轮次、OSS 发布和交付包完整性。

## 推荐接入结构

```text
ECS 接单
  -> ECS 后台任务队列
  -> gpt-5.6-sol 流式 API（900 秒客户端上限）
  -> HTML 校验与素材本地化
  -> OSS 发布与任务回写
```

这样可以取消对用户本机开机和本机 Worker 的依赖，但仍需保留 ECS 侧后台任务执行器，以承担长任务、重试、心跳、失败退款和发布回写。
