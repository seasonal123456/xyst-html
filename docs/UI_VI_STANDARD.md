# 项目推荐卡制作器 UI / VI 标准 v1

## 1. 产品名称

正式名称：

```text
项目推荐卡制作器
```

命名原则：

- 不露出供应商名称
- 不露出供应商或中转 API 品牌
- 页面不主动展示任何平台品牌信息
- 仅当 Excel 中自带公司名、项目名、园区名时，才在生成内容中出现对应品牌

## 2. 产品定位

```text
面向产业园、厂房、平台招商、选址推荐场景的项目推荐卡制作工具。
```

使用属性：

```text
公司权益内免费使用
限时开放
```

前端表达重点：

- 马上能上传
- 马上能看到最终推荐卡方向
- 不强调系统品牌
- 不做复杂营销解释
- 给客户的感觉是“这是一个好用、好看的在线制作工具”

## 3. 视觉总方向

客户前端视觉关键词：

```text
黑白灰
圆边
立体
阴影
投影
玻璃反光
双层半透明
果冻质感
高级工具页
```

整体气质：

```text
苹果官网式干净留白
+
果冻玻璃质感工具界面
+
产业园推荐卡最终产物强展示
```

避免：

- AI 紫色渐变
- 传统后台感
- 太多蓝白政企风
- 卡通插画
- 供应商品牌露出
- 复杂说明文案

## 4. 色彩标准

基础色：

```text
页面背景：#F5F5F7
主面板：rgba(255,255,255,.72) / #FFFFFF
主文字：#1D1D1F
正文：#333336
辅助文字：#6E6E73
分割线：rgba(0,0,0,.08)
```

立体阴影：

```text
主阴影：0 24px 80px rgba(0,0,0,.14)
轻阴影：0 12px 32px rgba(0,0,0,.08)
内高光：inset 0 1px 0 rgba(255,255,255,.75)
```

玻璃质感：

```text
背景：rgba(255,255,255,.58) 到 rgba(255,255,255,.82)
模糊：backdrop-filter: blur(20px) saturate(180%)
边框：1px solid rgba(255,255,255,.62)
反光：顶部或左上角使用半透明白色高光层
```

主操作色：

```text
黑色按钮：#1D1D1F
蓝色链接：#0066CC
成功/生成状态：#008F93
```

注意：

```text
推荐卡本身不强制纳入本工具 VI。
推荐卡颜色、排版、图标、背景风格以参考图复刻和 Image 2 创作为主。
```

## 5. 字体标准

前端 UI：

```text
-apple-system
BlinkMacSystemFont
SF Pro SC
PingFang SC
Microsoft YaHei
Arial
```

标题：

- 字重大
- 短句
- 不使用装饰字
- 不使用过多彩色字

正文：

- 尽量短
- 说明不超过两行
- 不堆功能介绍

按钮文字：

- 直接命令式
- 例如：上传 Excel、可选上传图片、开始制作、查看记录

## 6. 客户前端页面标准

客户前端必须是工具页，不是纯官网展示页。

进入页面第一屏必须马上看到：

```text
1. 上传 Excel
2. 可选上传项目图片
3. 开始制作按钮
4. 生成结果区域
```

当前客户前端显示的总模块仅保留：

```text
产品名
新建生成
生成结果
```

管理入口、会员登录说明、生成效果示例区、我的生成区均不在当前客户前端显示。

推荐首屏结构：

```text
顶部极简标题
  项目推荐卡生成器

主工作区
  上传表单占满宽度

下方
  生成结果
```

客户不应先看到：

- 长篇产品介绍
- 复杂会员解释
- 后台表格
- 注册登录表单
- 生成效果示例区
- 我的生成区

登录入口原则：

```text
正式产品使用官网会员系统。
工具页不单独展示“员工登录 / 新员工注册”。
本地原型使用隐藏演示会员模拟官网已登录状态。
```

## 7. 客户前端组件标准

上传区：

- 大圆角
- 白色半透明玻璃面板
- 文件状态清楚
- 一个区域只做一个动作

上传状态：

```text
未上传
已上传
校验中
校验通过
需要修正
```

生成按钮：

- 主按钮使用黑色或深灰
- 悬浮时轻微抬起
- 禁用态明显变浅

生成中：

- 不用普通转圈
- 使用线性进度或卡片逐张生成状态
- 文案简短：正在制作第 2 / 8 张

结果区：

- 推荐卡缩略图要大
- 不提供额外保存按钮
- 不提供 ZIP 下载按钮
- 图片由用户自行复制或保存
- 页面记录可展示生成码，推荐卡图片内不展示生成码

我的生成：

- 当前客户前端不展示该板块
- 员工生成记录仍需在数据层保留
- 不提供原始 Excel 下载
- 普通员工只看自己的记录

## 8. 管理端 UI 标准

管理端风格：

```text
iPad 工作台风
```

管理端应更实用，不强行做营销页。

布局：

```text
左侧导航
顶部概览
右侧主内容
白色工作台面板
浅灰背景
细分割线
轻阴影
```

优先页面：

```text
1. 公司权益
2. 员工 / 会员绑定
3. 生成批次
4. 生成码溯源
5. 失败记录
```

管理端按钮：

- 新建公司
- 生成公司码
- 延长有效期
- 调整次数
- 禁用公司
- 查询生成码

管理端禁忌：

- 不做大幅宣传首屏
- 不用过多玻璃反光
- 不牺牲表格可读性
- 危险操作必须明显

## 9. 推荐卡产物标准

推荐卡本身不强制统一进工具 VI。

目标：

```text
复刻用户提供参考图的颜色、排版、信息层级和视觉冲击力。
```

参考图关键要素：

- 顶部“项目推荐卡”
- 大项目名
- 右侧产业园 / 楼宇背景图
- 推荐标签大胶囊
- 图标 + 字段 + 内容列表
- 月租金强视觉价格带
- 环境描述
- 推荐理由
- 联系方式信息（用户可选填写时）

推荐卡生成方式：

```text
Excel 提供必要文案信息
  ↓
Image 2 收到文案后自由发挥制作项目推荐卡
  ↓
用户预览
  ↓
保存图片与生成记录
```

提示词原则：

- 提供必要字段
- 提供参考图方向
- 不限制 Image 2 的创作
- 不强制统一 VI
- 不露出工具品牌
- 不露出供应商品牌
- 同一批次传入统一风格要求，保证视觉相似

## 10. Image 2 使用原则

Image 2 在本工具中承担：

```text
最终项目推荐卡创作
```

已确认决策：

- Image 2 可以自由发挥并直接生成完整项目推荐卡
- 中文、数字、金额或联系方式偶尔偏差时，接受由用户预览确认来兜底
- 生成码只保留在系统记录和管理端溯源中，不交给 Image 2 绘制
- 同一批次推荐卡需要保持相似风格
- 客户上传的产业园图片可以作为参考，Image 2 可以自由重绘
- 管理端第一版只做平台管理员，不做公司负责人角色

输入：

- 项目名
- 位置
- 项目特点
- 通勤
- 车程
- 租金报价
- 月租金
- 环境描述
- 推荐理由
- 推荐标签
- 项目图片或园区图片，可选参考
- 参考图，可选

输出：

```text
完整项目推荐卡图片
```

产品侧需要保留：

- 原始提交资料
- 解析快照
- Image 2 请求记录
- 输出图片
- 生成码
- 用户和公司归属

## 11. 权益表达

前端文案建议：

```text
公司权益内免费使用
限时开放
```

不要强调：

- 免费白嫖
- AI 生图成本
- 供应商名称
- 技术实现细节

可以展示：

```text
当前公司：已开通
有效期：剩余 30 天
本批次：可制作
```

## 12. 已确认方向

以下方向已经确认，后续实现不再反复询问。

1. 产品名：项目推荐卡制作器
2. 客户前端：工具页，第一屏看到上传表单
3. 视觉：黑白灰、圆边、立体阴影、投影、玻璃反光、双层半透明果冻质感
4. 管理端：iPad 工作台风
5. 推荐卡：复刻参考图方向，不纳入工具 VI
6. Image 2：直接生成完整推荐卡，允许自由发挥
7. 文字准确性：用户预览确认兜底
8. 生成码：只保留在系统记录和管理端溯源，不显示在推荐卡图片中
9. 批次一致性：同一批次保持相似风格
10. 上传图片：可选；上传后可参考并自由重绘，未上传时使用默认画面生成
11. 管理角色：第一版只有平台管理员和普通员工
12. 首屏示例：第一屏除了上传表单，必须固定展示 3 张生成示例
13. 错误修正：用户发现某张卡文字错误时，支持只重新生成这一张
14. 风格强度：第一版不提供选择项，默认使用“精致”

## 13. 交互规则

以下交互已经确认：

1. 首屏固定展示上传表单和 3 张生成示例
2. 用户预览后发现 Image 2 文字错误，支持“只重新生成这一张”
3. 同一批次保持相似风格
4. 风格强度第一版不开放给用户选择，默认“精致”
